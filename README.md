# Scoreboard app
You select a user, while your browser is open, youre in control of them or something, i dont really want logins or anything but like i dont want people to be able to touch eachothers stuff.
a simple scoreboard:
  names -> points ordered by score
a teaming section to indicate which players are currently competing together
a "now playing" section for what game we are currently playing.

Admin view:
direct access to the database in case anything needs to be fixed
the ability to set teams
issuing points is done here
setting the current round / now playing bit

## Extras:
communal whiteboard, ability to put stickers on other players, pretty animations
